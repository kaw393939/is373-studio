# IS373 Studio

VitePress course guide for NJIT Fall 2026. Student instructions, examples, and career preparation.

Use `npm ci`, `npm run check`, `npm run docs:build`, and `npm run check:built`. GitHub Actions publishes `main` to https://kaw393939.github.io/is373-studio/. Canvas remains the source for official graded deadlines and submissions. No private course records belong in this public repository.

## Current student clarity resources (November 2026)

The course homepage has a next-class card, direct Plan submission links, and a simple two-Canvas-box/three-deliverable explanation. [Get unstuck](docs/course/get-unstuck.md) links the student's existing FastAPI/server work and current RAG learning guides.

**Canvas has not been modified by these GitHub changes.** A copy-ready [homepage](instructor/canvas-homepage.html), [RAG clarification announcement](instructor/canvas-rag-clarification.html), and [authenticated Canvas Student View checklist](instructor/CANVAS-UPDATE.md) are provided for an instructor to apply through Canvas. Do not claim the Canvas course is updated unless the changes are actually published and checked in Student View.
