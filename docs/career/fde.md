# What is a forward deployed engineer?

An **FDE** works closely with a customer or business team to build useful software. They learn how people work, find a problem worth solving, build a solution, and help people use it.

For example, a service company receives incomplete requests. An FDE might talk with staff, improve the request flow, connect it to existing data, and check whether it saves rework.

## What IS373 helps you practice

Trace content through a workflow, enforce permissions on the server, and check how applications and infrastructure work together.

| Professional habit | Your practice here |
| --- | --- |
| Understand the workflow | Identify who creates, checks, and publishes content. |
| Handle data responsibly | Use synthetic fixtures and a small, traceable content pipeline. |
| Build safe access | Test authentication and server-enforced permissions. |
| Operate a system | Use the existing server, CI, logs, and sanitized evidence. |
| Deliver with a team | Review, retest, explain ownership, and document handoff. |

This is a foundation. FDE roles often expect more programming, databases, cloud systems, customer work, or AI engineering. Read [job examples and pay](/career/jobs-and-pay) and [local internship leads](/career/internships) as targets to learn toward.
