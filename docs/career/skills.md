# Build one skill at a time

Use a role description to choose your next practice. You do not need to learn every professional tool this term.

| Skill | Evidence from IS373 | Build more depth later |
| --- | --- | --- |
| Content and data | Follow a synthetic item through create → check → publish. | SQL design, larger ETL pipelines, and data-quality monitoring. |
| Security | Check member/admin rules on the server, including denied requests. | Threat modeling, secure operations, and access audits. |
| Operations | Preserve existing services; verify HTTPS, container, and CI evidence. | Cloud architecture, logs, recovery, and monitoring. |
| Collaboration | Share feature work, review a partner’s change, and retest fixes. | Customer workshops and production handoff. |
| AI judgment | Explain AI’s help and verify the output yourself. | Model evaluation, retrieval, costs, latency, and human review. |

These are instructor learning connections, not a claim that passing the course meets an employer’s requirements. [See the work behind the titles](/career/jobs-and-pay).

## Turn a gap into a small next step

Instead of “learn cloud,” choose “deploy this small working app, record the setup, check one failure, and explain recovery.” Instead of “learn AI,” choose “compare two outputs against five known examples and record where they fail.” Keep private data and secrets out of public evidence.
