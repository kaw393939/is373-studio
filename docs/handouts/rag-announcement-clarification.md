# IS373 RAG resource clarification (instructor copy)

**This is an instructor-ready draft, not a posted Canvas announcement.** Canvas remains the official submission and deadline system. Publish or revise the text below in the existing announcement discussion if appropriate; do not treat the presence of this page as proof that Canvas students received it.

## Suggested follow-up to the November 10 RAG announcement

The [IS373 RAG project and student guides](https://kaw393939.github.io/is373-rag/students/) are available to help you finish your **existing individual RAG assignment**. They are a resource, not another project.

Start with one real question for a reader, about five short permitted documents, and five expected-evidence test questions (include an unanswerable one). You need to **research both vector and graph retrieval**, then justify implementing vector, graph or both.

Already have your App Studio FastAPI application and Docker/HTTPS server? **Reuse them.** See [from your FastAPI app to RAG](https://kaw393939.github.io/is373-rag/students/from-app-studio). If embeddings or chunking are unfamiliar, read those short [embeddings](https://kaw393939.github.io/is373-rag/students/embeddings) and [chunking](https://kaw393939.github.io/is373-rag/students/chunking) lessons first.

There are optional [AI coding prompts](https://kaw393939.github.io/is373-rag/students/prompts) and a [survey of libraries such as LangChain](https://kaw393939.github.io/is373-rag/students/library-survey). **No framework, paid API, local GPU, Rust implementation or model training is required by these new guides.** The sample offline lab is helpful practice but does **not** replace your real hosted RAG.

**November 17 Plan:** reader/problem, sources and permission, retrieval comparison and choice, import/retrieval diagram, expected evidence and hosting approach. A running RAG app is **not** required at Plan.

**November 24 Build:** small real hosted import → retrieval → model-generated answer with source references. Label local/mocked work honestly. **December 3 Release** adds persistence, actual checks and repeatable setup; **December 10 Improve** uses genuine peer feedback and a retest.

Bring your **current repository, one question, an actual result or exact blocker**. The [original course brief](https://github.com/kaw393939/is373-studio/blob/main/docs/projects/individual.md) and Canvas still define your work and grading.
