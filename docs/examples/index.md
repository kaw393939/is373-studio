## A short review update

An example of the size to aim for; use your own actual results and links.

> **Changed:** members can save private drafts and an admin can publish them.
> **Checked:** an unauthorized publish request is rejected; a published item appears to visitors. Reimporting the fixtures adds no duplicates.
> **Next:** ask a peer to try the review flow and fix the first obstacle.
> **Links:** source revision, test results and issue/PR in the existing record.

**Career value:** you can show a useful result and explain access, data and your checks. [What to hand in](/course/milestones).
