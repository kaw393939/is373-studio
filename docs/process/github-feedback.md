# Keep track of the improvement

Use an issue in **your project repository** for a feature or useful piece of feedback.

1. Say what should happen and what needs changing.
2. Make the change. Include the issue number in the commit message, such as `Make the result clearer (#12)`.
3. Check the result, link the change and close the issue when it is resolved.

For group work, name an owner and ask someone else to try the result. Record what actually happened. Keep required pull requests, reviews and CI checks from the posted Studio instructions.

```text
Task: A new user can find the next step.
Change: [commit or PR link]
Check: [who tried what, on which version, and what happened]
```

Put the issue link in the same project record. Canvas is where you submit coursework and receive grades. Private circumstances stay there too.
