# What to hand in

**Keep the same project record.** Submit the repository/record links requested by the Canvas assignment, with your current working version, relevant issue/PR and actual checks. Add a short **changed / checked / next** note. Name each person's contribution in the group record.

[See a short explanation](/examples/content-desk) · [Your next class](/course/section-001#before-next-class).

## Current Studio rubrics stay the same

Server Studio and App Studio each have 100 points:

| Published criterion | Points |
| --- | ---: |
| The agreed result works | 40 |
| Specification, actual checks and completed issue/PR evidence | 35 |
| Your own decisions, explanations and observations | 25 |

[Read each assignment's exact scope](/projects/studios). App Studio is local: deploying it is a later step. Do not add a hidden deployment requirement to that assessment.
